# c-language-study
C语言刷题代码、错题笔记与每日学习日志

## 📖 仓库介绍
本仓库记录我的C语言完整学习过程，跟着翁恺课程自学，在PTA平台刷题。
包含源代码、错题复盘、知识点总结、每日学习记录。

## 📂 目录结构
- `codes/`：C语言源代码（.c 文件）
- `notes/`：错题整理、知识点笔记
- `daily-log/`：每日学习日志

## 📝 学习计划
1. 基础语法：变量、运算符、分支、循环
2. 数组、函数
3. 指针、字符串
4. 结构体、文件
5. PTA基础编程题目集刷题
